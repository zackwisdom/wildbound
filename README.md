# WildBound

WildBound is a first-person hardcore wilderness survival game built with React, Vite, and Three.js.

## Current systems

- First-person WASD movement, mouse look, jumping, and sprinting
- Visible first-person hands plus torso, legs, and boots when looking down
- Procedural terrain, trees, rocks, berry bushes, ground clutter, fog, stars, and moon
- Day/night cycle with increasingly dangerous enemy spawns at night
- Health, hunger, stamina, inventory, harvesting, melee combat, walls, and campfires
- Tool unlock progression for axe and pickaxe

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

This repository is now the primary standalone codebase for WildBound and does not depend on Base44.
